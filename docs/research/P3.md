## R10 — Motion and 3D stack

- **Status:** in progress
- **Question:** which libraries and versions should the base site use for premium 3D motion?
- **Finding:**
  - `motion` is the current package (formerly Framer Motion). Import from `motion/react`. Latest seen: **14.10.1**.
  - `gsap` latest seen: **3.15.1**. GSAP is now **100% free for all users**, including ScrollTrigger, SplitText, and the rest of the plugin set, thanks to Webflow.
  - `three` **0.187.0**, `@react-three/fiber` **9.8.2**, `@react-three/drei` **10.7.9**, `@react-three/postprocessing` **3.2.2**.
  - `lenis` **1.3.27** for optional smooth scroll.
  - `next` **16.4.5**, `react` **19.3.1**, `tailwindcss` **4.3.5**.
- **Evidence:** npm registry `latest` tags; https://motion.dev/docs/react; https://gsap.com/pricing/
- **Impact on the build:**
  - Use Motion for UI animation, gestures, layout, and scroll-linked values.
  - Use GSAP only where a complex timeline or ScrollTrigger is clearly easier.
  - Use R3F + Drei only for the voxel hero, ASCII accent, and liquid shader; lazy-load with `ssr: false`.
  - Keep Lenis optional and disable it under reduced motion.

## R12 — Skiper UI and references

- **Status:** in progress
- **Question:** what can we learn from Skiper UI without copying it?
- **Finding:**
  - Skiper UI is a shadcn registry. Its documented prerequisites are Next.js, Tailwind, React, Motion (`framer-motion`), GSAP, `clsx`, `tailwind-merge`, `lucide-react`, and `react-use-measure`.
  - Free components require attribution; Pro components are paid and licensed.
  - The interaction patterns are the useful part: cursor trails, coverflow, drag/wheel grids, dynamic islands, image reveals.
- **Evidence:** https://skiper-ui.com/docs/quick-start · https://skiper-ui.com/
- **Impact on the build:**
  - Build original components with the same interaction ideas.
  - Do not copy Pro code or assets.
  - If a free component is used directly, add attribution.
